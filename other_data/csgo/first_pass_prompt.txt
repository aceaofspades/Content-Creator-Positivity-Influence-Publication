8. **technical** - Opinions on server stability, subtick system, bug fixes, performance/FPS, hit registration technology, load times, anti-cheat systems
9. **developer_communication** - Opinions on Valve communication, patch notes, update frequency, community feedback response, CSGO-to-CS2 transition handling, live service approach
10. **social_onboarding** - Opinions on new/returning player experience, community servers (surf, KZ, DM servers), in-game tutorials, team-finding, coaching system

Return ONLY a JSON object with a "categories" key containing an array of category names where the creator expresses opinions. No markdown, no explanation.
